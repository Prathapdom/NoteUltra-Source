NoteUltra 1.0 - Windows x64

Run NoteUltra.exe. Keep it beside Scintilla.dll, Lexilla.dll, and both license files.

Ctrl+N: New   Ctrl+O: Open   Ctrl+S: Save   Ctrl+W: Close tab
Ctrl+F: Find  Ctrl+H: Replace  Ctrl+G: Go to line
Ctrl+Alt+S: Split view   Alt+Z: Word wrap

Tabs, syntax highlighting, folding, bookmarks, find/replace, themes,
Unicode encoding, line-ending conversion, background Open/Save.

This first release is independent of Notepad++. Plugins, macros, session
restoration, crash recovery, printing, and folder-wide search are not included.
Save important work normally. Unsaved text is not automatically backed up.

This app is unsigned and has not been Microsoft Store certified.
Full source, build scripts, limitations, and validation notes are provided
in the accompanying NoteUltra source package.

No account or built-in network service is used. Files are processed locally.
Scintilla and Lexilla third-party licenses are included in this folder.
